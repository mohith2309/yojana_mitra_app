## 2026-06-07 - Replaced O(N) lookup inside ListView.builder with O(1) hash map\n**Learning:** In Flutter, calling `.where(...).firstOrNull` on a non-trivial list inside a `ListView.builder` can lead to performance regressions during scrolling, turning O(N) rendering into O(N*M). Caching the matches into a Map using a `Builder` wrapping the `ListView.builder` significantly optimizes list scrolling performance.\n**Action:** Whenever iterating through a list inside `itemBuilder` to find matching items, use a Map or Set cache initialized before the `ListView.builder` instead.
