## 2025-03-01 - Concurrency Optimization for Data Gov Aggregation
**Learning:** The FastAPI backend frequently aggregates data from multiple disparate government API endpoints (e.g., fetching from both the OGD feed and multiple distinct LGD resource IDs for villages, local bodies, and pincodes). Because these external calls are independent, performing them sequentially using individual `await` statements (an "N+1 sequential I/O" pattern) drastically bottlenecked endpoint latency.
**Action:** When an endpoint performs multiple independent external network calls, always bundle them together using `await asyncio.gather(...)` rather than awaiting them sequentially. This reduces the total I/O latency from the sum of all requests to merely the duration of the slowest single request, significantly speeding up the backend.
